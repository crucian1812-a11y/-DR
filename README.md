# Справочник по фен-стайлеру Tuvio HBI1414

Одностраничный сайт с подробным разбором мультистайлера Tuvio HBI1414 (оранжевая
версия линейки HBI1411–HBI1415): характеристики, все семь насадок, пошаговые укладки,
режимы, секреты, уход, диагностика, видеообзоры и FAQ.

## Что внутри

| | |
|---|---|
| Разделов | 28 |
| Насадок разобрано | 7 |
| Укладок по шагам | 9 |
| Видеообзоров | 12 |
| Таблиц-шпаргалок | 13 |

Структура:

1. **Знакомство** — что это за прибор, характеристики, комплектация, линейка HBI1411–1415, корпус и управление.
2. **Технологии** — BLDC-мотор, захват пряди потоком воздуха, ионизация, режимы, разбор всех насадок, подбор под задачу.
3. **Практика** — быстрый старт, подготовка волос, девять укладок по шагам, настройки под тип волос, тайминг.
4. **Мастерство** — секреты и лайфхаки, частые ошибки, стойкость укладки.
5. **Эксплуатация** — уход и чистка фильтра, безопасность, диагностика неисправностей, график обслуживания.
6. **Выбор и материалы** — сравнение с Dyson Airwrap, кому подходит, видеогид, FAQ, глоссарий, чек-листы, источники.

## Возможности страницы

- боковое оглавление с поиском по разделам и подсветкой активной секции;
- светлая и тёмная темы, выбор запоминается;
- видео подгружаются только по клику (превью вместо плеера) и фильтруются по темам;
- чек-листы с сохранением отметок в браузере;
- версия для печати: оглавление и элементы управления скрываются, аккордеоны раскрываются;
- адаптив от 360 px.

## Как открыть

Зависимостей и сборки нет — это статический HTML.

```bash
# локально
python3 -m http.server 8000
# затем http://localhost:8000
```

Или просто открыть `index.html` в браузере.

### GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка с этим кодом, папка `/ (root)`.

## Оговорка

Материал неофициальный и не связан с Tuvio и Яндексом. Технические характеристики
взяты из открытых карточек товара, приёмы укладки — из обзоров и общей практики работы
с фен-щётками. Значения, которые производитель не публикует (температура в градусах,
вес, длина шнура), в тексте намеренно отсутствуют. Официальный источник — инструкция
из коробки, общая для моделей HBI1411–HBI1415.
